SPEC-42 — Organização do backend e logs

Estrutura

  • backend/Massali.slnx: solução .NET.
  • backend/src/: projetos de domínio, aplicação, contratos, infraestrutura, API e workers.
  • backend/tests/: testes .NET.
  • backend/.config/, global.json, Directory.*.props e Dockerfile: ferramentas e compilação do backend.
  • frontend/: React, independente do contexto de build .NET.
  • log/: logs locais, não versionados; TestResults/ mantém relatórios de teste.

Aceite

Os dois arquivos Compose continuam na raiz. Build e testes continuam por Docker; as imagens da API e dos dois workers precisam compilar, os testes devem passar e os contextos local/Easypanel devem validar. Não alterar volumes nem dados ao reorganizar os arquivos. Referências históricas a src/ nos documentos anteriores passam a corresponder a backend/src/ no checkout; o caminho interno do container continua /workspace/src/.
