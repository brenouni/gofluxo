Identidade, concorrência e dados

Cada domínio conserva identificadores e versões próprios. A identificação do veículo ajuda a conferir o objeto, mas não deve substituir as chaves do ciclo de atendimento. A versão esperada impede sobrescrever alterações concorrentes; origem, ator e momento sustentam rastreabilidade. Campos listados aqui são nomes do esquema/modelo, sem dados preenchidos de clientes ou operações.

Como ler este mapa técnico

O inventário abaixo apresenta arquivos, símbolos e declarações de rotas encontrados na cópia de referência. A extração é estática: não confirma funcionamento em produção nem substitui leitura das políticas de autorização. As rotas compostas dinamicamente podem exigir consulta ao arquivo completo. Arquivos compartilhados são reutilizados entre frentes; a divisão documental não cria APIs ou bancos novos.
